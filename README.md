# Sistema de Cadastro de Produtos com Dashboard Gerencial

Sistema web completo para cadastro e gerenciamento de produtos, desenvolvido com Flask (Python), HTML, CSS e SQLite.

## 🚀 Como Executar

```bash
pip install -r requirements.txt
python app.py
```

Acesse: http://localhost:8009

## ✨ Funcionalidades

- **Dashboard Gerencial** com cards de métricas
- **Gráficos interativos** com Chart.js (lazy loading)
- **CRUD completo** de produtos
- **Design responsivo** (mobile-first)
- **Alertas de estoque baixo**

## 📁 Tecnologias

- Backend: Python 3 + Flask
- Banco: SQLite
- Frontend: HTML5 + CSS3 + Chart.js
- Porta: 8009
